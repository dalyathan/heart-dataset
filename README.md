# Cardiovascular Disease Prediction using Explainable AI

This repository contains code and analysis for developing and interpreting machine learning and deep learning models to predict cardiovascular disease (CVD). The project focuses on leveraging Explainable AI (XAI) techniques to understand the most influential features driving model predictions, and comparing these insights with traditional exploratory data analysis (EDA) findings.

## Project Objectives

* Develop an advanced deep learning model for predicting cardiovascular disease.
* Integrate Explainable AI (XAI) techniques (SHAP, LIME) to identify key influential features.
* Compare XAI results with exploratory data analysis findings to verify consistency of identified risk factors.

## Dataset

The project utilizes the [UCI Heart Disease Dataset](https://archive.ics.uci.edu/dataset/45/heart+disease), a widely recognized resource for cardiovascular disease prediction research.

## Models Implemented

* **Gaussian Naive Bayes (GNB):** A probabilistic baseline model.
* **Logistic Regression:** A robust linear classifier with hyperparameter tuning.
* **Support Vector Classifier (SVC):** A powerful classifier using a probabilistic kernel.
* **K-Nearest Neighbors (KNN):** A non-parametric, instance-based classifier.
* **CNN-LSTM Hybrid Model:** A deep learning architecture combining Convolutional Neural Networks and Long Short-Term Memory networks for enhanced feature extraction and temporal pattern learning.

## Explainable AI (XAI) Techniques

* **SHAP (SHapley Additive exPlanations):** A game-theoretic approach to explain individual predictions by quantifying each feature's contribution.
* **LIME (Local Interpretable Model-agnostic Explanations):** Provides local explanations for individual predictions by training interpretable models on perturbed data instances.

## Repository Structure

- **`confusion_matrices/`**  
  Includes images representing confusion matrices from model evaluations.

- **`lime_summaries/`**  
  Contains summaries generated by LIME for model interpretability.

- **`shap_summary_plots/`**  
  Holds SHAP summary plots illustrating feature importance.

- **`training_results/`**  
  Stores results and metrics from model training sessions.

- **`data_analysis.ipynb`**  
  Jupyter notebook for exploratory data analysis.

- **`lstm_cnn_heart_dataset.ipynb`**  
  Notebook implementing LSTM-CNN models for heart dataset.

- **`machine_learning_heart_dataset.ipynb`**  
  Notebook applying various machine learning algorithms to the dataset.

- **`util.py`**  
  Python script containing utility functions used across notebooks.

## Getting Started

To set up the environment and run the code:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/dalyathan/heart-dataset.git](https://github.com/dalyathan/heart-dataset.git)
    cd heart-dataset
    ```
2.  **Create and activate a virtual environment (recommended):**
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```
3. **Run Jupyter notebooks:**
    ```bash
    jupyter notebook
    ```
    Navigate to the `notebooks/` directory
